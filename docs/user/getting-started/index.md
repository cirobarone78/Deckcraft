Start DeckCraft, pick a theme tile under **New presentation**, then use **New Slide** on the **Home** tab to add slides. Press F5 to play the deck.

## Steps

1. [Install DeckCraft](install.md) and start it. The start screen shows **New presentation** with one tile per built-in theme.
2. Click a theme tile. A new deck opens.
3. On the **Home** tab, click **New Slide**. Click the arrow next to it to pick a layout for the new slide.
4. Click in a placeholder on the slide and type.
5. Press F5, or click **Present** in the title bar, to play the deck from the first slide. Press Esc to leave the show.
6. Press Ctrl+S to save. The first save asks where to put the file.

On macOS, use Cmd in place of Ctrl.

If you would rather try DeckCraft on a finished deck first, click **Open the sample deck** on the start screen.

## Find a command

Press Ctrl+Shift+P to open the command palette, which has a **Search commands…** box that finds any command by name. The magnifier icon at the right of the title bar opens it too.
